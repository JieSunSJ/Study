## 介绍
Apache Maven 是一个项目管理和构建工具,它基于项目对象模型(POM)的概念,通过一小段描述信息来管理项目的构建

作用:
```
方便的依赖管理
标准的项目构建流程
统一的项目结构
```
```
<?xml version="1.0" encoding="UTF-8"?>
<!--
  Maven 项目对象模型（POM）配置文件
  这是 Maven 项目的核心配置文件，定义了项目的基本信息、依赖和构建规则

  POM 文件结构说明：
  - <project>: 根元素，声明命名空间和 XML Schema
  - <modelVersion>: POM 模型版本，Maven 4.0.0 为当前默认版本
  - <groupId>: 项目所属组织/公司的唯一标识（通常用反向域名）
  - <artifactId>: 项目的唯一标识（项目名）
  - <version>: 项目版本号，SNAPSHOT 表示开发中的快照版本
-->
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <!-- 项目坐标（坐标 = groupId + artifactId + version，三者唯一确定一个构件） -->
    <groupId>cn.hytc</groupId>
    <artifactId>web-project</artifactId>
    <version>1.0-SNAPSHOT</version>

    <!--
      属性配置：定义项目的全局变量，可在 pom.xml 其他地方通过 ${属性名} 引用
      这里配置了 Java 编译版本和源码编码
    -->
    <properties>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>

    <!--
      依赖管理：声明项目所需要的外部库（jar 包）
      Maven 会自动从中央仓库（或配置的私服）下载这些依赖
      每个依赖同样通过 groupId + artifactId + version 来定位
    -->
    <dependencies>
        <dependency>
            <groupId>commons-io</groupId>
            <artifactId>commons-io</artifactId>
            <version>2.11.0</version>
        </dependency>
    </dependencies>
</project>
```
说白了，maven就是pom部分+dependency部分+插件部分（打包等）
dependency通过查找本地仓库的依赖来添加jar包，如果本地仓库没有就在远程仓库（私服）查找(如果有这个私服的话)，如果这两个都没有就在中央仓库查找
```
E:\develop\maven-3.8.1\local\commons-io\commons-io\2.11.0
//这是我自己的本地仓库，第一层groupId，第二层artifactId，第三层版本号
<groupId>commons-io</groupId>  
<artifactId>commons-io</artifactId>  
<version>2.11.0</version>
```
## 安装
```
安装步骤:
1. 解压 apache-maven-3.9.4-bin.zip。
2. 配置本地仓库:修改 conf/settings.xml 中的<localRepository>为一个指定目录。
<localRepository>D:\develop\apache-maven-3.9.4\mvn_repo</localRepository>
3. 配置阿里云私服:修改 conf/settings.xml 中的 <mirrors>标签,为其添加如下子标签:
<mirror>
<id>alimaven</id>
<name>aliyun maven</name>
<url>http://maven.aliyun.com/nexus/content/groups/public/</url>
<mirrorOf>central</mirrorOf>
</mirror>
4. 配置环境变量:MAVEN_HOME 为maven的解压目录,并将其bin目录加入PATH环境变量。
```
