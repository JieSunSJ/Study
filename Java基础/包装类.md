### 自动装箱和自动拆箱
JDK5才出现
自动装箱：JVM会自动的把基本数据类型装到一个对象当中,底层调用valuOf方法
自动拆箱：JVM会自动的把对象中的基本数据类型拿出来,底层intValue方法
```
Integer i1 = 100; // /rT: Integer i1 = Integer.valueOf(100);
Integer i2 = 200; // 4Mr T: Integer i2 = Integer.valueOf(200);

// 46r T: i1.intValue() + i2.intValue() = 300
Integer i3 = Integer.valueOf(300);
// Integer i3 = Integer.value0f(i1.intValue() +i2.intValue());
Integer i3 = i1 + i2;
System.out.print1n(i3);
```
