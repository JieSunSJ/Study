方法:程序中的独立功能,也是最小的执行单元
使用场景:经常使用的代码打包,放在方法当中
好处:提高了程序的复用性和可维护性
```
public static 返回值类型 方法名(参数1,参数2 ... ){
方法体;
return 返回值;
}
```
## 定义方法的小诀窍
观察在大段的代码当中,反复使用的独立功能是什么?
这个独立功能,需要什么才能完成 ?
方法的调用处,是否需要这个独立功能的结果继续做其他事情?
## 方法的重载
方法名一样，形参类型不一样，即方法重载，无需看返回值
## 注意点
方法不调用就不执行
方法与方法之间是平级关系,不能嵌套定义
调用方法会优先调用形参和实参一一对应的,如果没有才会进行隐式转换
return: 1. 结束方法 2.将结果返回给调用者
void:没有返回值,可以省略return不写
如果不省略,return后面不能写具体数据,仅表示结束方法
