数组:是一种容器,可以用来存储同种数据类型的多个值
数组是引用数据类型
引用型数据类型记录的是地址，基本数据类型记录的是真实的数据。
## 数组的静态初始化
初始化:是指在定义变量、数组、对象的时候进行赋值
静态:在定义变量、数组、对象的时候,数据是静止、确定的
静态初始化:创建数组的时候,直接给数组赋值
完整格式
```
int arr[] = new int[]{1,2,3}；
```
简写
```
int arr[] = {1,2,3}
```
特点：连续的空间；一旦定义，长度不可变；
## 数组的元素访问
### 索引
索引就是数组的一个编号,也叫作:角标、下标、编号
特点:从0开始的,连续+1,不间断
数组名[索引]
获取，修改
```
int num = arr[1];
arr[1] = 10;
```
## 数组的遍历
快捷 数组名.fori +回车
```
for(int i = 0;i < arr.length;i++){
sout(arr[i])
}
```
## 数组的动态初始化
动态:在定义变量、数组、对象的时候,数据是不确定的
初始化:创建数组的时候,直接给数组赋值
动态初始化:创建数组的时候指定长度,由系统为数组分配初始值
```
int arr[] = new int[3];
```

## 数组的内存分配
数组的初始化会用到堆内存
```
直接输出数组的索引会输出 [I@e33f 这种地址，[表示这是数组，I表示类型，@是分隔符，@后面是十六进制
```
## 数组在方法中传递
数组在方法中被引用时，其索引可以直接指向堆内存里面的数据
