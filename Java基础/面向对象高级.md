## 什么是继承？
继承是类与类之间的一种父子关系,Java中提供关键字extends,用于建立类与类之间的关系
面向对象三大特征之一,可以让类跟类之间产生父子的关系。
## 继承的好处
可以把多个子类中重复的代码抽取到父类中了,提高代码的复用性
子类可以在父类的基础上,增加其他的功能,使子类更强大
```
格式：
public class 子类 extends 父类 {}
```

```
父类
package com.hytc.edu.jicheng;  
  
public class Person {  
    String name;  
    int age;  
    public void eat() {  
        System.out.println("人吃东西");  
    }  
}
```

```

package com.hytc.edu.jicheng;  
  
public class Student extends Person {

## 继承的特点
Java只支持单继承,不支持多继承,但支持多层继承
单继承:一个子类只能继承一个父类
不能多继承:子类不能同时继承多个父类
子类和父类的关系有直接父类和间接父类
java中有一个顶级父类Object,JVM自动加的
## 继承中成员变量的特点
书写规则:把多个子类中相同的属性抽取到父类当中
子类中没有这个成员变量就会向父类找这个父类
如果子类中的局部变量想要调用父类的成员变量，要用super关键字
```
package com.hytc.edu.jicheng;

        Zi z = new Zi();  
        z.ziShow();  
    }  
}  
class Fu {  
    String name="Fu";  
}  
  
class Zi extends Fu{  
    String name="Zi";

        System.out.println(this.name);  
        System.out.println(super.name);  
    }  
}
```
## 继承中成员方法的特点
书写规则:把多个子类中共性的成员方法抽取到父类当中
### 方法的重写
方法重写:在子类中,把父类的方法再写一遍,方法申明保持一致
使用场景:如果父类的方法不能满足子类的要求了,子类中可以把该方法再重写一遍
重写会带有注解，和注释作用差不多，注释是给我自己看的，注解是给JVM看的
```
@Override  
public String toString() {  
}
```
### 方法重写注意事项和要求
重写方法的名称、形参列表必须与父类中的一致,方法体按照实际需求书写。
了解:子类重写父类方法时,访问权限子类必须大于等于父类(空着不写<protected<public)
了解:子类重写父类方法时,返回值类型子类必须小于等于父类(类也算)
建议:重写的方法申明和父类保持一致即可
final修饰类为最终类,不能被继承,里面所有的方法不能被重写
private私有方法，static静态变量，final最终方法不能被重写
## 继承中的构造方法
父类中的构造方法不会被子类继承,只能通过super关键字调用
```
package com.hytc.edu.jicheng;  
  
public class T {  
    public static void main(String[] args) {  
        Zi z = new Zi("Zi", 18,1);  
        System.out.println(z.name);  
        System.out.println(z.age);  
        System.out.println(z.id);  
    }  
}  
class Fu {  
    String name;  
    int age;  
    public Fu(){  
    }  
    public Fu(String name, int age){  
        this.name = name;  
        this.age = age;  
    }  
}  
  
class Zi extends Fu{  
    int id;  
    public Zi(){  
        super();  
    }  
    public Zi(String name,int age,int id){  
        super(name, age);  
        this.id = id;  
    }  
}
```
继承结构当中构造方法的小细节:
子类构造方法第一行,有一个默认的super(),如果我们没有书写,JVM也会自动加上
如果想要访问父类的带参构造,super(参数)必须手动写上,不能省略
在创建对象的时候,先执行父类的构造方法,再执行子类的构造方法
## this和super关键字
this内存的角度:表示当前方法调用者的地址值
this代码的角度:利用this可以直接调用本类成员(比如:成员变量,成员方法,构造方法等)
super关键字:代表使用父类中的内容
this():调用本类的其他构造方法
```
public Student() { 1 usage
this( "i", 18);
}

public Student(String name, int age) {
this.name = name;
this.age = age;
}
```
细节:
如果子类中有多个构造方法的时候,不能用this()互功调用,一定要预留一个调用父类的构造方法
如果构造方法当中写上了this(),就不能再写super(),JVM也不会自动添加super();
在老版本当中this()只能写在构造方法的第一行,但是在新版本当中去掉了这一限制

## 子类到底能继承父类的哪些内容？
构造方法:不能被子类继承,可以利用super关键字调用
成员变量:可以被子类继承,private私有的也可以,但是私有的无法直接调用
成员方法:虚方法可以被继承（虚方法就是普通的成员方法，非static,final,private修饰的方法）
final修饰的最终方法不能被继承,可以被调用
static修饰的静态方法不能被继承,可以被调用
private修饰的私有方法不能被继承,不能被调用

## Java中的权限修饰符
private:同一个类
空着不写:同一个类，本包中其他类
protected:同一个类，本包中其他类，不同包下的子类
public:同一个类，本包中其他类，不同包下的子类，不同包下的无关类
作用范围由小到大(private<空着不写<protected<public)

### 类型转换
自动类型转换(从子到父):
```
子类对象赋值给父类类型的变量
```
强制类型转换(从父到子):
```
子类 对象变量=(子类)父类类型的变量
```
将父类强制转换成子类，这样子类的独有方法就可以使用了

## 抽象类
抽象方法所在的类就是抽象类，有abstract关键字的就是抽象
抽象方法:
```
将共性的行为(方法)抽取到父类之后。因为每一个子类的方法体是不一样,
所以,在父类中不能确定具体的方法体。该方法就可以定义为抽象方法。
public abstract 返回值类型 方法名(参数列表);
```
抽象类:
```
如果一个类中存在抽象方法,那么该类就必须声明为抽象类
public abstract class 类名{ .. }
```
抽象类不能实例化
```
如果可以创建抽象类的对象的话,用对象调用一个没有方法体的抽象方法,没有任何意义。
```
抽象类中不一定有抽象方法,有抽象方法的类一定是抽象类
```
为了不让外界创建本类的对象
```
抽象类中可以有构造方法
```
构造方法是为了给成员变量赋值
```
抽象类的子类
```
要么重写抽象类中的所有抽象方法(正常内容)
要么子类也是抽象类(意义不大)
```

## 接口
接口:接口就是一个规则,而且是独立于继承体系以外的规则。(可以理解为干爹)
格式:关键字interface来定义
使用:接口和类之间的是实现关系,通过implements关键字表示
```
public class 类名 implements 接口{ .. }
```
注意点1:接口不能实例化
注意点2:接口的子类(实现类),要么重写接口中所有的抽象方法,要么实现类是一个抽象类
注意点3:一个类可以实现多个接口,也可以在继承一个类的同时,实现多个接口
实现类：
```
package com.hytc.edu.Test1;  
  
public class Dog extends Animal implements Swim {  
    public Dog(String name, String color) {  
        super(name, color);  
    }  
    @Override  
    public void eat() {  
        System.out.println("狗吃骨头");  
    }  
    @Override  
    public void swim() {  
        System.out.println("狗游泳");  
    }  
}
```
接口：
```
package com.hytc.edu.Test1;  
  
public abstract interface Swim {  
    public abstract void swim();  
}
```
接口中成员的特点
```
成员变量:只能是常量。默认修饰符:public static final，常量必须赋值
构造方法:没有,因为不需要再赋值
成员方法:只能是抽象方法。默认修饰符:public abstract
```

继承关系,只能单继承,不能多继承,但是可以多层继承
类和接口的关系
实现关系,可以单实现,也可以多实现,还可以在继承一个类的同时实现多个接口
接口和接口的关系
继承关系,可以单继承,也可以多继承
```
如果一个类实现了多个接口，那么就要重写多个接口的所有方法(废话，本来也就要重写)
如果多个接口包括父类，出现了重复的方法，那么实现类里面只要重写一次
## 接口在JDK8和JDK9的新特性
```
JDK7以前:接口中只能定义抽象方法
JDK8的新特性:接口中可以定义有方法体的方法
JDK9的新特性:接口中可以定义私有方法
```
### JDK8以后接口中新增的方法
```
接口中默认方法的定义格式:
格式:public default 返回值类型 方法名(参数列表){}
范例:public default void show(){ }

接口中默认方法的注意事项:
默认方法不是抽象方法,所以不强制被重写。但是如果被重写,重写的时候去掉default关键字
public可以省略,default不能省略
如果实现了多个接口,多个接口中存在相同名字的默认方法,子类就必须对该方法进行重写
```
允许在接口中定义默认方法,需要使用关键字default修饰
作用:为了接口升级时,代码不报错
默认方法不是抽象方法,所以不强制被重写。但是如果被重写,重写的时候去掉default关键字
public可以省略,default不能省略
如果实现了多个接口,多个接口中存在相同名字的默认方法,子类就必须重写该方法
```
package com.hytc.edu.Test2;  
  
public abstract interface Say {  
     abstract void say();  
     default void acton(int a){  
        System.out.println("我是一个人，我有" + a + "岁");  
    }  
}
```
允许在接口中定义定义静态方法,需要用static修饰
接口中静态方法的定义格式:
```
格式:public static 返回值类型 方法名(参数列表){}
范例:public static void show(){ }
```
接口中静态方法的注意事项:
```
静态方法只能通过接口名调用,不能通过实现类名或者对象名调用
public可以省略,static不能省略
```
### JDK9新增的私有方法
为了抽取默认方法和静态万法中重复代码而出现的
主要是为了让外界访问不到
默认方法提取私有
格式1:private返回值类型 方法名(参数列表){}
范例1:private void show(){ }
静态方法提取私有
格式2:private static 返回值类型 方法名(参数列表){}
范例2:private static void method(){ }
```
package com.hytc.edu.Test2;  
  
public interface InterB {  
    default void Method1(int a){  
        System.out.println("这是默认方法");  
        Method3();  
    }  
    default void Method2(){  
        System.out.println("这是默认方法");  
        Method3();  
    }  
    private void Method3(){  
        System.out.println("从默认方法中调用私有方法");  
    }  
    static void Method4(){  
        System.out.println("这是静态方法");  
        Method6();  
    }  
    static void Method5(){  
        System.out.println("这是静态方法");  
        Method6();  
    }  
    private static void Method6(){  
        System.out.println("从静态方法中调用私有静态方法");  
    }  
}
```
## 内部类
内部类:在一个类的里面,再定义一个类
### 为什么会有内部类呢?
```
需求:写一个Javabean类描述汽车
属性:汽车的品牌,车龄,颜色,发动机的品牌,使用年限
```
发动机也是一个独立的个体

内部类表示的事物是外部类的一部分

## 成员内部类(了解)
写在成员位置的，属于外部类的成员
成员内部类可以被一些修饰符所修饰,比如:private,默认,protected,public,static等
在成员内部类里面,JDK16之前不能定义静态变量,JDK16开始才可以定义静态变量
创建对象
```
获取成员内部类对象的两种方式:
方式一:外部类编写方法,对外提供内部类对象
方式二:直接创建
格式:外部类名.内部类名 对象名=外部类对象.内部类对象;
范例:Outer.Inner oi = new Outer().new Inner();
```
内部类的内存地址表示：外部类名$内部类名@内存地址

成员内部类如何获取外部类的成员变量
```
package com.hytc.edu.work3;  
  
public class Outer {  
    private int a = 10;  
    class Inner{  
        private int a = 20;  
        public void show(){  
            int a = 30;  
            System.out.println(Outer.this.a); // 10  
            System.out.println(this.a); // 20  
            System.out.println(a); // 30  
  
        }  
  
    }  
}
```
## 静态内部类
静态内部类只能访问外部类中的静态变量和静态方法
如果在静态内部类中,想要访问外部类非静态的内容,需要创建外部类的对象
创建静态内部类的对象:
```
外部类名.内部类名 对象名= new 外部类名.内部类名();//注意new的是内部对象，就一个()
```
调用静态内部类中非静态方法的格式:
```
先创建对象,用对象调用
```
调用静态内部类中静态方法的格式:
```
外部类名.内部类名.方法名();
```

```
package com.hytc.edu.work3;  
  
public class Outer {  
    static int a = 10;  
    private int b = 20;  
    static class Inner{  
        Outer outer = new Outer();  
        public void show(){  
            System.out.println(a);  
            System.out.println(outer.b);  //先创建对象,用对象调用
        }  
  
    }  
}
```
### 局部内部类
1. 将内部类定义在方法里面就叫做局部内部类,类似于方法里面的局部变量。
2. 外界是无法直接使用,需要在方法内部创建对象并使用。
3. 该类可以直接访问外部类的成员,也可以访问方法内的局部变量。
### 匿名内部类
就是一个没有名字的内部类
作用:在继承一个类或者实现一个接口的时候少写一个文件,也是lambda的前置知识点
定义格式:
```
new 类名或者接口名(){
重写方法;
};
```

匿名内部类的定义格式=没有名字的java类+继承/实现+重写方法+创建对象
最终格式可以理解为:是一个没有名字的java类的对象
没有名字的java类:大括号
Swim:就是这个没有名字的java类实现了swim接口
重写方法:我们要在大括号当中重写swim所有的抽象方法
创建对象:new关键字作用的是后面这个合格没有名字的java类,创建了他的对象
整体:创建了一个Swim实现类的对象,只不过这个类没有名字而已
```
Swim s = new Swim(){
@Override 1 usage
public void swim() {
System.out.println("学生正在游泳”);
}
};

goSwimming(s);
```
使用场景
如果实现类只要使用一次,就可以用匿名内部类简化代码
