```
移除元素
给你一个数组nums和一个值val,你需要删除所有数值等于val的元素
举例1:
输入:nums=[3,2,2,3] val=3
输出:nums=[2,2]剩余2个元素
举例1:
输入:nums=[0,1,2,2,3,0,4,2] val=2
输出:nums=[0,1,4,0,3]剩余5个元素
```
解：
```
public class main {  
    public static void main(String[] args) {  
        int fast=0,slow=0;  
        int nums[] = {0,1,2,2,3,0,4,2};  
        int val = 2,num=0;  
        while(fast<nums.length){  
            if(nums[fast]!=val){  
                nums[slow] = nums[fast];  
                slow++;  
                num++;  
            }  
            fast++;  
        }  
        for (int i = 0; i <num; i++) {  
            System.out.print(nums[i]);  
        }  
    }  
}
```

```
红包问题

给你两个整数M和N,M表示红包的总额,N表示红包的个数
现在又N个人来抽红包,每个人都是随机的,打印每个人领的红包金额
```

```
解
package com.hytc.edu.leet;  
  
import java.util.Random;  
  
public class main {  
    public static void main(String[] args) {  
        int M,N;  
        M = 3;  
        N = 5;  
        M*=100;  
        double [] nums=new double[N];  
        Random random = new Random();  
        for (int i = 0; i < N-1; i++) {  
            nums[i] = random.nextInt(1,M-N+1);  
            M-=nums[i];  
            System.out.println("第"+i+"个人抢到为"+nums[i]*0.01);  
        }  
      System.out.println("第"+N+"个人抢到为"+M*0.01);  
    }  
}
```

```
中位数
给定两个正序数组arr1和arr2,请先合并数组,并找出合并之后数组的中位数。
举例:
123456789
123456
中位数:5
中位数:(3+4)/2
```

```
解
package com.hytc.edu.leet;  
  
import java.util.Random;  
  
public class main {  
    public static void main(String[] args) {  
        int[] arr = {1,2,3,4,5,6,7,8,9};  
        int[] arr1 = {1,2,3,4,5,6};  
        int[] arr2 = new int[arr.length+arr1.length];  
        int slow = 0;  
        int fast = 0;  
        while (slow+fast < arr2.length) {  
            if(slow==arr.length) {  
                arr2[slow + fast] = arr1[fast];  
                fast++;  
            }else if(fast==arr1.length) {  
                arr2[slow + fast] = arr[slow];  
                slow++;  
            }else  
            if (arr[slow] < arr1[fast]) {  
                arr2[slow + fast] = arr[slow];  
                slow++;  
            } else {  
                arr2[slow + fast] = arr1[fast];  
                fast++;  
            }  
        }  
        for (int i = 0; i < arr2.length; i++) {  
            System.out.print(arr2[i]);  
        }  
        if(arr2.length%2==0){  
            int midnum1 = arr2[arr2.length/2];  
            int midnum2 = arr2[arr2.length/2-1];  
              
            System.out.println((midnum1+midnum2)/2);  
        }else{  
            System.out.println(arr2[arr2.length/2]);  
        }  
    }  
}
```

```
统计个数

学校选举学生会主席,有5个候选人
全校1000名同学参与投票(每人一票,可以弃权,或者选1-5号)。
投票使用Random模拟。0:弃权,1~5:给对应的候选人投票
要求1:
统计每个候选人的得票数和得票率,找出得票最多的候选人?
要求2:
统计弃票数和弃票率是多少?
```

```
package com.hytc.edu.leet;  
  
import java.util.Random;  
  
public class main {  
    public static void main(String[] args) {  
        Random random = new Random();  
        int[] arr = new int[5];  
        int q = random.nextInt(1001);  
        for (int i = 0; i < 1000; i++) {  
            int num = random.nextInt(5);  
            arr[num]++;  
        }  
        for (int i = 0; i < arr.length; i++) {  
            System.out.println(i+"出现的次数为："+arr[i]+"得票率为："+(arr[i]/10.0)+"%");  
        }  
        System.out.println("弃票数为:"+q+"弃票率为："+(q/10.0)+"%");  
    }  
}
```
