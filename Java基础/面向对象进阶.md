## static修饰成员变量
static:表示静态,是Java的修饰符,用来修饰(成员变量/成员方法)
特点:叫做静态变量,被该类所有对象共享
调用方式:
方式一:类名调用
方式二:对象名调用

只要有一个对象对静态变量进行了修改，其他所有的都会修改
主要是可以被类名调用
static 可以使枚举类在没有对象的情况下可以被直接调用
## static关键字的内存解析
静态变量是随着类的加载而加载的,优先于对象出现的
静态变量和方法区的字节码文件差不多，虚拟机没有关闭就会一直存在
## static关键字修饰成员方法
特点:
static修饰的方法叫做静态方法
该方法多用在测试类和工具类中
Javabean类中很少会用
调用方式:
方式一:类名调用
方式二:对象名调用

```
工具类：
不是用来描述一类事物的,也没有main方法,而是帮我们做一些事情的类
1.类名见名知意
2.私有化结构方法
3.方法定义为静态
```

```
工具类的使用
package com.hytc.edu.statictest.toolclasstest;  
  
public class arrUtil {  
    private arrUtil() {  
    }  
    public static void printArr(int[] arr) {  
        for (int i = 0; i < arr.length; i++) {  
            System.out.print(arr[i] + " ");  
        }  
        System.out.println();  
    }  
    public static int getAverage(int[] arr) {  
        int sum = 0;  
        for (int i = 0; i < arr.length; i++) {  
            sum += arr[i];  
        }  
        return sum / arr.length;  
    }  
}


package com.hytc.edu.statictest.toolclasstest;  
  
public class Test {  
    public static void main(String[] args) {  
        int[] arr = {1, 2, 3, 4, 5};  
        arrUtil.printArr(arr);  
        System.out.println(arrUtil.getAverage(arr));  
    }  
}
```
## 静态的注意事项
1.静态方法只能访问静态变量和其他的静态方法
2.非静态方法可以访问静态变量或者静态方法,也可以访问非静态的成员变量和非静态的成员方法
3.静态方法中是没有this关键字

总结:静态只能调用静态,非静态可以调用所有,静态方法无this

原因是，静态方法是和类一起被加载的，当时的堆内存里面也只有静态，就算后续加载进来了，也不知道内存地址，因为是用的类名调用的静态方法，而不是对象，所以没有调用者地址，静态变量跟对象无关
而非静态是和对象一起被创建的，并且不能用类名调用

### 重新认识main方法
public:被JVM调用,访问权限最大
static:被JVM调用,类名访问
测试类中其他方法也是静态的
void:不需要给JVM返回值
main:固定的名字,被JVM识别
String[] args:用于接收运行的参数,目前不用

## final关键字
final修饰的变量叫做常量，因为不可改变
final:表示最终,不可变。可以修饰变量、类、方法
特点1:只能赋值一次,数据不可变
特点2:名字大写,多个单词下划线隔开
```
final int NUMBER = 10;//不可改变NUMBER
final Student STU = new Student();//不可改变对象的这个内存地址，因为这是引用型数据类型
如果想让类里面的成员变量也变的不可修改，可以直接在前面加final
```
一个例子
```
package com.hytc.edu.statictest.toolclasstest;  
  
public class yuan {  
    private final double PII = 3.14;  
    private  int R;  
    public yuan() {  
    }  
    public yuan(int R) {  
        this.R = R;  
    }  
  
    public int getR() {  
        return R;  
    }  
  
    public void setR(int r) {  
        R = r;  
    }  
  
    public double getArea() {  
        return PII * R * R;  
    }  
}


package com.hytc.edu.statictest.toolclasstest;  
  
public class Test {  
    public static void main(String[] args) {  
        yuan y = new yuan(5);  
        System.out.println(y.getArea());  
  
    }  
}
```
如果编程中发现一个数据是写死的不能变的，那就可以用final
## 枚举
枚举是一个特殊的Javabean类,这个类的 对象是有限个
使用场景:订单的状态、月份、星期、游戏角色职业、会议室预约状态、设备状态 ...
枚举的定义格式
用enum
所有的枚举项，默认使用public static final修饰的
```
package com.hytc.edu.statictest.toolclasstest;  
  
public enum meiju {  
    // 枚举类成员变量  
    DAIZHIFUNG("待支付"),  
    YIZHIFU("已支付"),  
    YIJIEKUAN("已借款"),  
    YIJIEKUANZH("已还款");  
    private String name;  
    //空参构造方法用不到，所以删了  
    private meiju(String name) {  
        this.name = name;  
    }  
    public String getName() {  
        return name;  
    }  
}

package com.hytc.edu.statictest.toolclasstest;  
  
public class Test {  
    public static void main(String[] args) {  
        //获取枚举类的对象  
        meiju daizhifung = meiju.DAIZHIFUNG;  
        System.out.println(daizhifung.getName());  
    }  
}
```

## 枚举的注意事项
1.每一个枚举项,都是该枚举类的对象,每一个对象都是通过构造方法创建出来的
2.枚举项在底层其实就是常量,默认用public static final修饰
```
可以在out目录的命令行输入javap meiju.class进行反编译，这样就可以看见那些看不见的public static final
```
3.枚举类的第一行上必须是枚举项,枚举项之间用逗号隔开,以分号作为结尾
4.枚举类的构造方法必须是private修饰,不让外界创建本类的对象
```
构造函数里面的形参对应着枚举类里面的值，如果枚举项没有参数那就对应着无参构造，枚举类的构造方法默认使用private修饰，不写的话JVM也会自动加上
```
5.编译器会给枚举类新增两个默认存在的方法:values(),valueOf()
```
values()：表示获取本类所有的枚举项
valueOf()：表示获取一个指定的枚举项
```
